🚀 CodePractice AI
📌 Project Description
CodePractice AI is an interactive learning platform built with Streamlit that helps users learn and practice Python and PostgreSQL. It tracks learning progress and provides simple recommendations based on completed lessons.

🎯 Objectives

- 🐍 Learn Python interactively
- 🐘 Learn and practice PostgreSQL
- 💻 Practice code and SQL queries
- 📊 Track lesson progress automatically
- 🎯 Recommend topics that need more practice
- 🧑‍💻 Provide a simple, user-friendly learning dashboard

✨ Key Features

- 🏠 Interactive Dashboard
- 🐍 Python Learning & Try Yourself
- 🐘 PostgreSQL Learning & Run Query
- 📈 Automatic progress percentage
- 🔄 Continue Learning
- 🎯 Recommended for You
- 📊 My Progress
- 🔖 Bookmarks
- ⚙️ Settings
- 🗄️ PostgreSQL database integration

🛠️ Technology

- 🐍 Python
- 🎨 Streamlit
- 🐘 PostgreSQL
- 🔌 Psycopg2
- 🔐 python-dotenv
- 🌐 HTML/CSS
- 🔧 Git & GitHub
- 💻 VS Code
